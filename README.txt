GITHUB PAGES - PRIVACY POLICY

Files
- privacy-policy.html : bilingual (English / Bahasa Indonesia) privacy policy page.

BEFORE UPLOADING
1. Open privacy-policy.html.
2. Search for [INSERT YOUR WEBSITE URL] and [MASUKKAN URL WEBSITE], then replace them with your published website URL.
3. Replace privacy@yourdomain.com (both the mailto link and visible email) with an email address you monitor.
4. Confirm that AuTuMN STUDIO is the correct site or business name. Change it everywhere if necessary.
5. Review the assumptions in the highlighted notice. This template assumes a static site without forms, accounts, checkout, analytics, advertising pixels, or non-essential cookies. Update the policy if your website uses any of these.

PUBLISH ON GITHUB PAGES
1. Upload privacy-policy.html to the root folder of the repository that publishes your website (usually the same folder as index.html).
2. Commit and push the change.
3. After GitHub Pages finishes publishing, open:
   https://YOUR-USERNAME.github.io/privacy-policy.html
   For a project site, use:
   https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/privacy-policy.html
4. Add a link to this page from your site's footer or navigation:
   <a href="privacy-policy.html">Privacy Policy</a>

NOTES
- The page is a standalone HTML file and uses no external CSS, JavaScript, fonts, or image assets.
- GitHub Pages documents that visitor IP addresses are logged and stored for security purposes. The page links to GitHub's own privacy statement.
- This is a general template, not legal advice. Review the page against your actual data practices and applicable laws before publishing.
